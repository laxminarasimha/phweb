# Prasanthi Hospitals — live content templates

**Partial source snapshot**

These three templates were read from the active Prasanthi Hospitals theme through the WordPress Theme File Editor on 7 October 2026. This folder is not a complete or installable theme. It excludes the remaining templates, stylesheet, functions, uploads, plugins and database.

- `prasanthi-hospitals/front-page.php`: Home, including the dynamic doctor cards.
- `prasanthi-hospitals/page.php`: About Us, Services and Contact Us text.
- `prasanthi-hospitals/footer.php`: shared footer.

**Review and publication**

The initial snapshot preserves the live files before this content update. Later commits show the text replacements. Keep the existing PHP, markup, attributes, styling, icons and links when applying copy updates. Do not install this partial folder as a replacement theme.

Doctor profiles are WordPress posts and metadata. Their portable editorial content lives in [the WordPress content pack](../content/wordpress/README.md). A Git push does not publish these changes to WordPress; the live dashboard requires separate save and public read-back.
