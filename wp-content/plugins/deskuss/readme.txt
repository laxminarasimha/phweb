A modern helpdesk and ticketing system for WordPress. Manage customer support tickets, departments, staff, and knowledge base articles with ease.

== Description ==

Deskuss is a revolutionary WordPress plugin that transforms your customer support experience. With Deskuss, you can easily manage tickets, provide timely responses, and ensure customer satisfaction. Say goodbye to complex ticketing systems and hello to a seamless support solution. Improve your customer satisfaction and streamline your support process with Deskuss.

= Features =

* Ticket Management – Create, assign, and track support tickets.
* Departments – Organize tickets by department for efficient routing.
* Staff Roles – Manage staff permissions with admin, manager, and staff roles.
* Knowledge Base – Build a self-service knowledge base for customers.
* Custom Forms – Create dynamic forms to collect ticket information.
* Email Notifications – Automatic email alerts for ticket updates.
* SLA Management – Set and monitor service level agreements.
* Canned Responses – Save time with reusable reply templates.
* Dashboard & Reports – Track team performance and ticket metrics.

== How to install Deskuss ==
Go To your WordPress install -> Plugins -> Add New Button -> In Search Box search For Deskuss -> Click on Install.

== Changelog ==

= 1.0.7 (Sep 21, 2026) =
* [Task] Improved security checks for plugin updates by verifying plugin signatures before upgrading.
* [Bug-Fix] Fixed PHP warnings.

= 1.0.6 (Aug 03, 2026) =
* [Added] Auto-Close: automatically close tickets inactive for a configurable number of days (default 7). Only tickets an agent has replied to are eligible for auto-close — unanswered tickets are never auto-closed.
* [Added] New "Pending" ticket state with "In Progress" status to park tickets an agent is actively working on. Pending tickets are skipped by Auto-Close.
* [Added] Auto-Close dry-run mode to log candidates without closing them.
* [Added] "Auto-Close Notice" email template sent to the customer on auto-close (optional).
