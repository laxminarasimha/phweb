# Prasanthi Hospitals WordPress Theme

This is a lightweight custom WordPress theme based on the current Prasanthi Hospitals HTML design.

## Install
1. Zip the `prasanthi-hospitals` folder.
2. In WordPress: Appearance > Themes > Add New > Upload Theme.
3. Upload the ZIP and activate it.
4. Set the Site Title and Custom Logo under Appearance > Customize (or Site Editor depending on WordPress setup).
5. Create a Primary Menu under Appearance > Menus.
6. Set the homepage to a static page or use the theme's front page template.

## Important
The doctor profile URLs are currently structured as:
- /doctor/dr-cn-murthy/
- /doctor/dr-csk-aditya/
- /doctor/dr-nishteshwar/

The profile content is intentionally a placeholder. During the full WordPress build, these should be converted to editable WordPress doctor profile pages/custom post types.

The theme does not collect or store patient health information. Do not add sensitive patient information to a basic WordPress form without a suitable secure/healthcare-compliant workflow.
